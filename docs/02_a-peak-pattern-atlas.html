We can now use the .plot_atlas() method to create an interactive holoviews plot.

ppa.plot_atlas()

In case you want to compare the atlas against another plot (such as a measured or a computed spectrum) it will be more useful to create a matplotlib axes object. This can be done by setting the ax= option.

fig, axs = plt.subplots(nrows=2, sharex=True, figsize=[10, 10])
ax0, ax1 = axs.flatten()
ppa.plot_atlas(ax=ax0)

xrf = ElementXRF('Pb', h_mm=0.01) 
xrf.plot_spectrum(ax=ax1);
