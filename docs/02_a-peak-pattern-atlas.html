Peak pattern atlas

The forest and the trees

The basic idea of X-Ray Fluorescence is that each chemical element has a unique pattern of emission peaks. Roughly speaking the relative intensity of the emission peaks does not change too much.

from moseley import PeriodicTable, PeakPatternAtlas, ElementXRF
import holoviews as hv 
import matplotlib.pyplot as plt
hv.extension('bokeh')
ⓘ 
table = PeriodicTable()
table.plot_table();

Ready building Peak Pattern Atlas!

We can now use the .plot_atlas() method to create an interactive holoviews plot.

ppa.plot_atlas()

In case you want to compare the atlas against another plot (such as a measured or a computed spectrum) it will be more useful to create a matplotlib axes object. This can be done by setting the ax= option.

fig, axs = plt.subplots(nrows=2, sharex=True, figsize=[10, 10])
ax0, ax1 = axs.flatten()
ppa.plot_atlas(ax=ax0)

xrf = ElementXRF('Pb', h_mm=0.01) 
xrf.plot_spectrum(ax=ax1);
